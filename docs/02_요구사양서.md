# 디미고 해킹방어과 입시 준비 사이트 — 요구사양서 (SRS)

- 문서 버전: v1.0 (2026-07-30)
- 관련 문서: 01_유즈케이스명세서.md, 03_개발계획서.md, 디미고_입시_준비_가이드.md

## 1. 개요

### 1.1 목적
2027학년도 디미고 해킹방어과 진학을 목표로 하는 중3 수험생이 **적성검사 이론/실전문제 → 해킹방어과 특화 기초 이론 → 면접 예상질문/연습 → 전형 정보(입시 가이드)** 를 한 곳에서 준비할 수 있는 **static 학습 웹사이트**를 구축한다.

### 1.2 범위
- 포함: 콘텐츠 열람, 모의고사(자동채점), 오답노트, 면접 연습, 체크리스트, D-day, 검색, 입시가이드 페이지
- 제외(현재 범위 아님): 회원가입/로그인, 서버 DB, 결제, 실시간 채점 랭킹, 타인과의 데이터 공유(멀티유저)
- **저작권 원칙**: 실제 학교 기출문제·저작권이 있는 대회 기출문제를 무단 게재하지 않는다. 문제은행은 공개된 유형·개념을 참고해 **자체 제작한 예상문제**로 구성하고, 출처가 있는 참고자료는 링크로만 안내한다.

### 1.3 용어 정의

| 용어 | 정의 |
|---|---|
| 적성검사 | 디미고 일반전형 2단계에서 시행되는 소질·적성검사(정보교과 역량/수리추론/문제해결/창의융합 사고력) |
| 문제은행 | 모의고사·연습문제 데이터 집합(JSON) |
| 콘텐츠 관리자 | 저장소의 콘텐츠 파일을 직접 편집하는 운영자(학부모/개발자) |
| Static Site | 빌드 시점에 정적 HTML/JS/CSS로 생성되어 별도 서버 없이 호스팅되는 사이트 |

## 2. 대상 사용자 및 사용 환경

- 주 사용자: 중학교 3학년 수험생 (본인 학습용, 데스크톱/모바일 모두 사용 — 등하교 중 모바일로 이론 복습 가능해야 함)
- 부 사용자: 학부모 (진행상황 확인용, 주로 데스크톱)
- 브라우저: 최신 Chrome, Edge, Safari, 모바일 Safari/Chrome 지원

## 3. 기능 요구사항 (Functional Requirements)

각 FR은 01_유즈케이스명세서.md의 UC와 매핑된다.

### FR-1. 대시보드 (UC-01)
- FR-1.1 영역별(적성검사 이론/모의고사/해킹방어 이론/면접) 진행률을 %로 표시한다.
- FR-1.2 D-day 위젯을 표시한다.
- FR-1.3 최근 오답 요약(최대 5개)과 "오늘의 추천 학습" 항목 1~3개를 표시한다.
- FR-1.4 데이터가 없는 최초 방문 시 온보딩 안내를 표시한다.

### FR-2. 이론 콘텐츠 (UC-02)
- FR-2.1 이론 콘텐츠는 아래 대분류로 구성한다 (세부 목차는 6장 콘텐츠 요구사항 참고).
  1. 적성검사 공통: 정보교과 기초, 수리추론, 문제해결·알고리즘 사고, 창의사고력 수학, IT 시사상식
  2. 해킹방어과 특화 입문: 정보보호개론, 네트워크 기초, 리눅스/CLI 기초, C언어·자료구조 기초, 웹 해킹 입문, 리버싱 입문, 포너블 입문, 암호학 기초
- FR-2.2 각 챕터는 "핵심 개념 → 예시 → 확인 문제(1~3개) → 요약"의 구조를 따른다.
- FR-2.3 각 챕터에 "학습 완료" 체크 기능을 제공하고, 완료 상태는 localStorage에 저장한다.
- FR-2.4 코드/터미널 예시는 syntax highlight로 표시한다.

### FR-3. 적성검사 모의고사 엔진 (UC-03)
- FR-3.1 문제 유형은 객관식(단일/복수 선택), 단답형(주관식 텍스트/숫자)을 지원한다.
- FR-3.2 모의고사는 "세트" 단위(예: 수리추론 세트, IT상식 세트, 웹해킹 개념 세트, 종합 모의세트)로 구성하고 세트별 제한시간을 둔다.
- FR-3.3 응시 중 타이머를 표시하고, 종료 시 자동 제출한다.
- FR-3.4 제출 즉시 자동 채점하여 총점, 영역별 정답률, 문항별 정오답과 해설을 제공한다.
- FR-3.5 회차별 결과(점수/일시)를 누적 저장하고, 추이를 간단한 차트(라인/바)로 시각화한다.
- FR-3.6 "오답노트에 저장" 액션을 제공한다.

### FR-4. 오답노트 (UC-04)
- FR-4.1 오답 문제를 최근순 또는 영역별로 조회할 수 있다.
- FR-4.2 오답 문제를 재풀이할 수 있으며, 정답 시 "복습완료" 상태로 전환한다(목록에서 제거하지 않고 상태만 표시하여 학습 이력 보존).

### FR-5. 면접 준비 (UC-05)
- FR-5.1 면접 질문은 카테고리(지원동기/실적물·포트폴리오/진로계획·직무이해/인성·태도/보안 시사이슈)로 분류한다.
- FR-5.2 각 질문에는 "출제 의도/평가 포인트" 힌트와 답변 작성 가이드(구조: 결론→근거→경험사례)를 함께 제공한다.
- FR-5.3 사용자가 답변 초안을 텍스트로 작성·저장할 수 있다(localStorage, 질문 ID별 저장).
- FR-5.4 "타임어택 모드": 무작위 질문 제시 + 60~90초 카운트다운 타이머(사용자가 초 설정 가능).
- FR-5.5 답변 작성 글자 수 카운터를 제공한다.

### FR-6. 전형 일정/D-day (UC-06)
- FR-6.1 전형 단계(원서접수, 1단계 결과, 2단계 적성검사·면접, 최종발표 등) 타임라인을 표시한다.
- FR-6.2 각 일정은 "확정" 또는 "예정(가안)" 상태 배지를 함께 표시한다.
- FR-6.3 D-day는 가장 임박한 주요 일정 기준으로 자동 계산한다.

### FR-7. 체크리스트 (UC-07)
- FR-7.1 「디미고 입시 준비 가이드」의 체크리스트 항목을 그대로 노출하고 체크 상태를 저장한다.
- FR-7.2 체크리스트 진행률을 대시보드(FR-1.1)에 반영한다.

### FR-8. 검색 (UC-08)
- FR-8.1 이론/문제/면접질문의 제목·태그 및 본문 일부(이론 본문 요약, 문항 해설, 면접 답변 가이드)를 대상으로 클라이언트 사이드 검색을 제공한다(빌드 시 생성된 정적 검색 인덱스 사용).
- FR-8.2 검색 결과는 카테고리별로 그룹핑해 표시한다.
- FR-8.3 검색어와 정확히 일치하지 않아도(오타·부분 일치) 유사한 결과를 찾아주며, 일치한 단어는 결과에서 강조 표시한다.
- FR-8.4 어느 페이지에서든 단축키(`/` 또는 Ctrl/Cmd+K)로 검색 입력에 바로 진입할 수 있다.

### FR-9. 입시 가이드 (UC-09)
- FR-9.1 기존 「디미고 입시 준비 가이드」 문서를 사이트 페이지로 변환해 제공한다(목차 네비게이션 포함).
- FR-9.2 확정 요강 발표 시 관리자가 손쉽게 내용을 갱신할 수 있도록 마크다운 소스 그대로 사용한다.

### FR-10. 콘텐츠 데이터 구조 (UC-10)
- FR-10.1 모든 콘텐츠(이론/문제/면접질문/일정)는 코드와 분리된 파일(Markdown/JSON)로 관리한다(7장 데이터 모델 참고).
- FR-10.2 콘텐츠 추가 시 코드 수정 없이 파일 추가만으로 반영되도록 한다(빌드 시 자동 목록화).

## 6. 콘텐츠 요구사항 (상세)

### 6.1 적성검사 공통 이론 (5개 대분류)
1. **정보교과 기초**: 컴퓨터의 구성(하드웨어/소프트웨어), 이진수·자료 표현, 알고리즘·순서도 기초, 프로그래밍 기본 개념(변수/조건/반복)
2. **수리추론**: 규칙 찾기(수열/도형 패턴), 논리추론 문제, 경우의 수·확률 기초
3. **문제해결·알고리즘 사고**: 절차적 사고 문제, 의사코드 읽고 결과 예측하기, 디버깅형 문제(코드의 오류 찾기)
4. **창의사고력 수학**: 사고력 수학 유형(도형, 규칙, 논리 퍼즐)
5. **IT 시사상식**: AI, 빅데이터, IoT, 클라우드, 최근 보안 이슈 등 뉴스 기반 상식 카드

### 6.2 해킹방어과 특화 입문 이론 (8개 대분류) — 전국 중학생 IT 올림피아드 '해킹방어' 부문(웹/리버싱/포너블/MISC) 및 학과 커리큘럼(자료구조·정보보호·네트워크·컴퓨터시스템·프로그래밍·IoT)을 참고해 **중학생 눈높이 입문 수준**으로 구성
1. **정보보호개론**: 정보보안 3요소(기밀성/무결성/가용성), 대칭키/공개키 암호 개념, 악성코드 종류 개념
2. **네트워크 기초**: OSI 7계층/TCP-IP 4계층, IP/포트 개념, HTTP 요청·응답 구조
3. **리눅스/CLI 기초**: 기본 명령어(ls, cd, cat, grep 등), 권한 개념, 리눅스 마스터 자격증 소개
4. **C언어·자료구조 기초**: 변수/포인터 개념, 배열, 스택/큐 기초
5. **웹 해킹 입문**: XSS·SQL Injection·파라미터 조작 등 "개념 이해" 수준(실습 대신 개념+사례 중심)
6. **리버싱 입문**: 리버스 엔지니어링이 무엇인지, 실행파일 구조 개념(중학생 수준 개요)
7. **포너블 입문**: 버퍼오버플로우·포맷스트링 등 취약점 개념(개념 설명 중심, 코드 실습은 지양)
8. **암호학 기초**: 시저 암호 등 고전 암호부터 현대 암호 개념까지 흥미 위주 소개

> ⚠️ 실제 해킹 기법의 실습형 콘텐츠(익스플로잇 코드 작성 등)는 중학생 대상 교육 목적에 맞지 않으므로 **개념 이해와 방어적 관점** 중심으로 구성한다. 실습이 필요한 수준은 입학 후 학교 정규 교육과정에서 다룬다.
