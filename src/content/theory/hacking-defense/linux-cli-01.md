## 핵심 개념 1 — 왜 검은 화면에 글자를 치나요

컴퓨터를 쓸 때 우리는 보통 아이콘을 더블클릭하고, 파일을 드래그해서 옮겨요. 이렇게 그림으로 조작하는 방식을 **GUI**(Graphical User Interface, 그래픽 사용자 인터페이스)라고 해요.

반대로 **CLI**(Command Line Interface, 명령줄 인터페이스)는 글자로 명령을 적어서 컴퓨터에게 시키는 방식이에요. 이 글자를 입력하는 창을 **터미널**이라고 불러요.

처음 보면 "왜 굳이 불편하게?" 싶지만, 이유가 분명해요.

| GUI(마우스) | CLI(터미널) |
| --- | --- |
| 눈에 보여서 배우기 쉬움 | 처음엔 명령어를 외워야 함 |
| 파일 100개 이름 바꾸기 = 100번 클릭 | 한 줄로 100개 한꺼번에 처리 |
| 화면이 있어야 함 | 화면 없는 서버에도 접속 가능 |
| 내가 한 일을 기록하기 어려움 | 명령어를 그대로 저장 = 자동화·재현 가능 |

특히 세상의 웹 서버 대부분은 **리눅스**로 돌아가고, 그 서버에는 모니터가 달려 있지 않아요. 원격으로 접속해서 글자로만 관리해야 하죠. 보안 담당자가 "이 서버에 누가 언제 접속했지?"를 확인하려면 결국 터미널에서 로그 파일을 뒤져야 해요. 그래서 정보보안을 공부하려면 리눅스 CLI가 사실상 기본기예요.

## 핵심 개념 2 — 디렉터리 트리와 경로

리눅스의 파일 구조는 **거꾸로 자란 나무**예요. 맨 위에 뿌리(root)가 있고 아래로 가지가 뻗어요. 이 뿌리를 `/` 라고 써요.

```
/
├── home
│   └── student
│       ├── study
│       │   └── network.txt
│       └── memo.txt
├── etc
└── var
    └── log
```

폴더를 리눅스에서는 **디렉터리**라고 불러요. 위 그림에서 `network.txt` 파일이 있는 위치를 두 가지 방법으로 말할 수 있어요.

- **절대경로**: 뿌리(`/`)에서부터 전부 적는 방식 → `/home/student/study/network.txt`
- **상대경로**: 지금 내가 서 있는 위치에서부터 적는 방식 → 내가 `/home/student` 에 있다면 `study/network.txt`

절대경로는 "서울특별시 강남구 ○○로 12"처럼 완전한 주소예요. 상대경로는 "여기서 두 블록 앞 건물"처럼 내 위치에 따라 달라지는 안내죠.

경로를 쓸 때 자주 나오는 기호 세 개만 기억하세요.

| 기호 | 뜻 | 예시 |
| --- | --- | --- |
| `.` | 지금 있는 디렉터리 | `./run.sh` = 여기 있는 run.sh |
| `..` | 한 단계 위 디렉터리 | `cd ..` = 상위 폴더로 이동 |
| `~` | 내 홈 디렉터리 | `~/study` = /home/student/study |

## 핵심 개념 3 — 명령어의 생김새

터미널 명령은 대부분 이 모양이에요.

```
명령어  [옵션]  [대상]
  ls     -l    study
```

- **명령어**: 무엇을 할지 (`ls` = 목록 보기)
- **옵션**: 어떻게 할지. 보통 `-` 로 시작해요 (`-l` = 자세히)
- **대상**: 무엇에 대해 할지 (파일이나 디렉터리 이름)

옵션은 붙여 쓸 수도 있어요. `ls -l -a` 와 `ls -la` 는 같은 뜻이에요.

그리고 리눅스는 **대소문자를 구분해요**. `Memo.txt` 와 `memo.txt` 는 완전히 다른 파일이에요. 윈도우와 다른 점이라 처음에 많이 헷갈립니다.

## 예시 — 손으로 따라 해 보는 10분

아래 명령들을 위에서부터 순서대로 쳐 보세요. `$` 는 입력하라는 표시니까 빼고 치면 돼요. `$` 아래 줄은 컴퓨터가 보여주는 결과예요.

### 지금 어디에 있는지 확인하고 둘러보기

```bash
$ pwd
/home/student

$ ls
memo.txt  study

$ ls -l
-rw-r--r-- 1 student student   48 Jul 30 14:02 memo.txt
drwxr-xr-x 2 student student 4096 Jul 30 14:00 study
```

`pwd` 는 **print working directory**, 지금 서 있는 곳을 알려줘요. `ls` 는 목록(list), `-l` 을 붙이면 크기·시간·권한까지 자세히 보여줘요. 맨 앞이 `d` 로 시작하면 디렉터리예요.

### 이동하기

```bash
$ cd study
$ pwd
/home/student/study

$ cd ..
$ pwd
/home/student

$ cd ~
```

`cd` 는 **change directory**. 아무것도 안 쓰고 `cd` 만 치면 홈으로 돌아와요. 길을 잃었다 싶으면 `cd ~` 하고 `pwd` 로 위치를 확인하는 습관을 들이세요.

### 만들고, 보고, 복사하고, 옮기기

```bash
$ mkdir practice
$ cd practice

$ echo "OSI 7계층 복습" > note.txt
$ cat note.txt
OSI 7계층 복습

$ cp note.txt note-backup.txt
$ ls
note-backup.txt  note.txt

$ mv note-backup.txt old-note.txt
$ ls
note.txt  old-note.txt
```

- `mkdir` = make directory, 디렉터리 만들기
- `echo "글자" > 파일` = 글자를 파일에 써 넣기 (`>` 는 화면 대신 파일로 보내라는 뜻)
- `cat` = 파일 내용을 화면에 쭉 출력
- `cp` = copy, 복사 (원본 유지)
- `mv` = move, 이동. 같은 위치에서 쓰면 **이름 바꾸기**가 돼요

### 찾기

파일이 많아지면 눈으로 못 찾아요. 이때 `grep` 이 등장해요. 파일 안에서 특정 글자가 들어간 **줄**을 골라내 줍니다.

```bash
$ cat log.txt
2026-07-30 10:11 login success user=alice
2026-07-30 10:12 login fail    user=bob
2026-07-30 10:13 login fail    user=bob
2026-07-30 10:20 login success user=carol

$ grep fail log.txt
2026-07-30 10:12 login fail    user=bob
2026-07-30 10:13 login fail    user=bob

$ grep -c fail log.txt
2
```

`-c` 는 개수만 세는 옵션이에요. 보안에서 "로그인 실패가 짧은 시간에 몇 번이나 있었나"를 확인하는 건 침입 탐지의 가장 기본적인 작업이에요. 그걸 딱 두 줄로 해낸 거죠.

한 명령의 결과를 다음 명령에 넘기는 **파이프(`|`)** 를 쓰면 더 강력해져요.

```bash
$ ls -l | grep txt
-rw-r--r-- 1 student student 20 Jul 30 14:30 note.txt
-rw-r--r-- 1 student student 20 Jul 30 14:31 old-note.txt
```

### 모르면 물어보기

```bash
$ man ls
$ ls --help
```

`man` 은 매뉴얼(manual)이에요. 화면이 길어지면 방향키로 넘기고 `q` 를 눌러 빠져나옵니다. 명령어를 다 외울 필요는 없어요. **찾는 법을 아는 게 실력**이에요.

## 핵심 개념 4 — 파일 권한(permission)

`ls -l` 의 맨 왼쪽에 나온 `-rw-r--r--` 같은 암호문이 바로 **권한**이에요. 리눅스는 여러 사람이 한 컴퓨터를 같이 쓰는 걸 전제로 만들어졌기 때문에, "누가 이 파일을 읽고 쓸 수 있는가"를 파일마다 정해 둬요. 정보보호 3요소 중 **기밀성**과 **무결성**을 지키는 가장 기초적인 장치죠.

열 칸을 이렇게 끊어 읽어요.

```
 -   rwx   r-x   r--
 │    │     │     │
종류 소유자 그룹  기타 사용자
```

- **종류**: `-` 는 일반 파일, `d` 는 디렉터리
- **소유자(user)**: 파일을 만든 사람
- **그룹(group)**: 같은 팀으로 묶인 사용자들
- **기타(other)**: 그 외 모든 사람

각 자리의 세 글자는 이런 뜻이에요.

| 글자 | 이름 | 파일일 때 | 디렉터리일 때 |
| --- | --- | --- | --- |
| `r` | read | 내용을 읽을 수 있음 | 안에 뭐가 있는지 목록을 볼 수 있음 |
| `w` | write | 내용을 고칠 수 있음 | 안에 파일을 만들거나 지울 수 있음 |
| `x` | execute | 프로그램으로 실행할 수 있음 | 그 디렉터리 안으로 들어갈 수 있음 |
| `-` | 없음 | 해당 권한 없음 | 해당 권한 없음 |

### 숫자로 줄여 쓰기

권한은 `chmod`(change mode) 명령으로 바꿔요. 이때 `rwx` 를 숫자로 줄여 쓰는 관습이 있어요. 켜짐/꺼짐을 2진수로 보고 자릿값을 더하는 방식이에요.

| 권한 | 2진수 | 계산 | 숫자 |
| --- | --- | --- | --- |
| `---` | 000 | 0 | **0** |
| `--x` | 001 | 1 | **1** |
| `-w-` | 010 | 2 | **2** |
| `r--` | 100 | 4 | **4** |
| `r-x` | 101 | 4+1 | **5** |
| `rw-` | 110 | 4+2 | **6** |
| `rwx` | 111 | 4+2+1 | **7** |

즉 `r=4, w=2, x=1` 을 더하면 돼요. 세 그룹을 이어 붙이면 세 자리 숫자가 됩니다.

```bash
$ ls -l note.txt
-rw-r--r-- 1 student student 20 Jul 30 14:30 note.txt

$ chmod 600 note.txt
$ ls -l note.txt
-rw------- 1 student student 20 Jul 30 14:30 note.txt
```

`600` = 소유자 `rw-`(6), 그룹 `---`(0), 기타 `---`(0). 나만 읽고 쓸 수 있는 상태가 됐어요. 비밀번호나 개인 메모처럼 남이 보면 안 되는 파일에 쓰는 설정이에요.

자주 쓰는 조합을 정리하면 이래요.

| 숫자 | 표기 | 흔한 쓰임 |
| --- | --- | --- |
| 600 | `rw-------` | 나만 보는 설정 파일, 개인 키 |
| 644 | `rw-r--r--` | 일반 문서, 웹 페이지 파일 |
| 700 | `rwx------` | 나만 들어가는 개인 디렉터리 |
| 755 | `rwxr-xr-x` | 프로그램, 공개 디렉터리 |
| 777 | `rwxrwxrwx` | **아무나 고칠 수 있음 — 쓰면 안 되는 설정** |

`777` 은 "안 되면 일단 777" 같은 말이 돌 정도로 흔한 실수인데, 서버에서 이렇게 해 두면 누구든 파일을 바꿔치기할 수 있어요. 실제 웹 서버 사고의 원인으로 자주 지목되는 잘못된 설정이에요. **권한은 필요한 만큼만 주는 것(최소 권한의 원칙)** 이 보안의 기본 원칙입니다.

## 안전하게 연습하는 법

리눅스 명령은 확인을 잘 안 물어봐요. 지운 파일은 휴지통에 가지 않고 그냥 사라집니다. 그래서 **내 컴퓨터의 진짜 파일 말고, 망가져도 되는 연습장에서** 시작하는 게 좋아요.

| 방법 | 설명 | 특징 |
| --- | --- | --- |
| 온라인 터미널 | 웹 브라우저에서 바로 실습 | 설치 없음, 가장 부담 없는 시작 |
| WSL | 윈도우 안에서 리눅스를 실행하는 기능 | 윈도우 사용자에게 가장 편함 |
| 가상머신(VM) | VirtualBox 등에 리눅스를 통째로 설치 | 스냅샷으로 되돌리기 가능, 가장 안전 |
| 라즈베리파이 | 소형 컴퓨터에 리눅스 설치 | 실제 서버처럼 다뤄 볼 수 있음 |

연습할 때 지킬 것.

- 홈 디렉터리 아래에 `~/practice` 같은 **연습 전용 폴더**를 만들고 그 안에서만 작업하기
- 삭제 명령을 쓰기 전에는 `ls` 로 대상이 맞는지 먼저 확인하기
- 인터넷에서 본 명령어를 뜻도 모른 채 복사해서 붙여 넣지 않기 (특히 `sudo` 가 붙은 명령)
- 시스템 디렉터리(`/etc`, `/var`, `/usr`)의 파일은 지금 단계에서 건드리지 않기
- 남의 컴퓨터·학교 서버에서 실습하지 않기. 허락받지 않은 시스템에 접속하는 것 자체가 법 위반이에요

## 참고 — 리눅스마스터 자격증

리눅스 실력을 정리해 두고 싶다면 **리눅스마스터**(한국정보통신진흥협회 시행) 자격증이 있어요.

- **2급**: 1차는 필기 객관식, 2차도 필기 형태예요. 리눅스의 기본 개념, 파일 시스템과 디렉터리 구조, 기본 명령어, 권한 관리, 사용자 관리, 네트워크 기초 등을 다뤄요. 오늘 배운 내용이 그대로 시험 범위 안에 들어갑니다.
- **1급**: 서버 운영과 관리를 깊게 다루는 상위 등급이에요.

중학생도 응시할 수 있고, 응시 자격에 학력 제한이 없어요. 다만 **자격증 자체가 목표가 되면 안 돼요.** 디미고 면접에서 중요한 건 "자격증이 있다"가 아니라 "직접 서버를 만져 보다가 이런 걸 알게 됐다"는 이야기예요. 2급 교재를 실습 로드맵처럼 쓰면서 실제로 터미널을 두드려 보는 쪽이 훨씬 남습니다. (시험 일정과 세부 과목은 해마다 바뀔 수 있으니 반드시 공식 시행처 공고를 확인하세요.)

## 확인 문제

**문제 1.** 지금 `/home/student` 에 있어요. `/home/student/study/network.txt` 파일의 내용을 보려고 합니다. (1) 디렉터리를 이동한 뒤 파일을 여는 방법과 (2) 이동하지 않고 한 번에 여는 방법을 각각 명령어로 써 보세요.

<details>
<summary>정답 확인</summary>

**정답:**

```bash
# (1) 이동한 뒤 열기
cd study
cat network.txt

# (2) 이동하지 않고 상대경로로 한 번에
cat study/network.txt

# (2)를 절대경로로 써도 결과는 같아요
cat /home/student/study/network.txt
```

**해설:** `cat` 은 대상 파일의 경로를 받을 수 있으므로 굳이 `cd` 로 이동하지 않아도 돼요. 지금 위치가 `/home/student` 이므로 상대경로 `study/network.txt` 와 절대경로 `/home/student/study/network.txt` 는 같은 파일을 가리킵니다. 절대경로는 내가 어디에 있든 항상 통한다는 장점이 있어요.

</details>

**문제 2.** `ls -l` 결과가 `-rwxr-x---` 로 나왔어요. (1) 이 파일을 `chmod` 숫자 표기로 바꾸면 몇 번인가요? (2) 그룹에 속하지 않은 다른 사용자는 이 파일로 무엇을 할 수 있나요?

<details>
<summary>정답 확인</summary>

**정답:** (1) `750`  (2) 아무것도 할 수 없어요 (읽기·쓰기·실행 모두 불가)

**해설:** 맨 앞 `-` 는 일반 파일이라는 표시라 숫자 계산에서 제외해요. 나머지 아홉 칸을 셋씩 끊으면 소유자 `rwx`, 그룹 `r-x`, 기타 `---` 입니다.

- 소유자 `rwx` = 4+2+1 = **7**
- 그룹 `r-x` = 4+0+1 = **5**
- 기타 `---` = 0+0+0 = **0**

그래서 `chmod 750 파일이름` 이에요. 기타 사용자 자리가 모두 `-` 이므로 그룹 밖의 사용자는 이 파일에 손댈 수 없어요. 프로그램을 팀 안에서만 실행하게 할 때 자주 쓰는 설정입니다.

</details>

**문제 3.** 웹 서버의 설정 파일 권한을 확인했더니 `-rw-rw-rw-` (666) 이었어요. 어떤 점이 위험하고, 어떻게 고치는 게 좋을까요?

<details>
<summary>정답 확인</summary>

**정답:** 서버에 접근할 수 있는 **모든 사용자가 설정 파일을 수정**할 수 있어서 위험해요. 소유자만 쓸 수 있게 `chmod 644`(또는 더 엄격하게 `chmod 600`)로 낮춰야 합니다.

**해설:** 기타 사용자 자리에 `w`(쓰기)가 열려 있다는 게 핵심 문제예요. 공격자가 낮은 권한으로라도 서버에 발을 들이면 설정 파일을 마음대로 바꿔 서비스를 망가뜨리거나 접속 대상을 몰래 바꿔치기할 수 있어요. 이건 정보보호 3요소 중 **무결성**이 깨지는 상황이에요.

설정 파일에 비밀번호 같은 정보가 들어 있다면 읽기 권한도 막아야 하니 `600` 이 더 적절합니다. 판단 기준은 언제나 **"이 파일에 정말 그 권한이 필요한가?"** 예요. 필요 없으면 준 적이 없어야 합니다.

</details>

## 요약

- **CLI(터미널)** 는 글자로 컴퓨터를 조작하는 방식이에요. 반복 작업 자동화, 화면 없는 서버 관리, 작업 기록·재현에 강해서 보안 실무의 기본기예요.
- 리눅스 파일 구조는 `/` 를 뿌리로 하는 **트리**예요. 뿌리부터 다 쓰면 **절대경로**, 현재 위치 기준이면 **상대경로**. `.`(현재), `..`(상위), `~`(홈) 세 기호를 기억하세요.
- 기본 명령은 `pwd`(위치) · `ls`(목록) · `cd`(이동) · `cat`(내용 보기) · `mkdir`(폴더 만들기) · `cp`(복사) · `mv`(이동·이름변경) · `grep`(내용 검색) · `man`(설명서). 다 외우기보다 **찾는 법**을 익히세요.
- 권한은 `종류 + 소유자 + 그룹 + 기타` 로 읽고, `r=4 w=2 x=1` 을 더해 `chmod 644` 처럼 숫자로 씁니다. `777` 은 위험하고, **최소 권한의 원칙**이 정답이에요.
- 실습은 반드시 **연습 전용 폴더나 가상머신·WSL** 처럼 망가져도 되는 곳에서. 뜻을 모르는 명령은 붙여 넣지 않고, 허락받지 않은 시스템은 절대 건드리지 않아요.
