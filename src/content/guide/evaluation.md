*(최근 연도 기준 참고치)*

| 항목 | 비고 |
|---|---|
| 교과 성적(내신) | 중학교 2·3학년 국어·영어·수학 중간·기말 성적 중심, 배점 감소 추세(150점→120점) |
| 소질·적성검사 | 40점 내외 배점으로 신설/강화된 항목 |
| 출결 점수 | 결석·지각 등 반영 |
| 봉사활동 | 반영 비율은 크지 않으나 정량 반영 |
| 생활기록부(상장, 임원 활동, 독서기록 등) | 내신 비중이 줄면서 상대적으로 중요도 상승 |
| 자격증 | 반영 점수가 축소되는 추세(최근 폐지 예정으로 언급됨 — 확정 여부 확인 필요) |

> 학교 사이트의 "교과점수계산기" 메뉴에서 일반전형(120점 만점)/진로적성특별전형(총점 ÷ 2) 기준으로 예상 내신 점수를 직접 계산해볼 수 있습니다.
