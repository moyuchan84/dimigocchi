*(2027학년도 신입생 입학전형요항 확정안, 2026.07.30 발표 기준 — 총점 200점)*

| 항목 | 일반전형 | 진로적성특별전형 |
|---|---|---|
| 교과점수 | 120점 (1학년 2학기~3학년 2학기 국·영·수) | 60점 |
| 학교생활기록부 종합평가 | 20점 | 20점 |
| 활동증빙자료 | - | 60점 (대회입상 등급별 60/55/51/48점, 창업특기·자기추천 실적설명서 41~60점) |
| 자기소개서 | - (제출 의무 없음) | 20점 (5등급, 20~16점) |
| 소질·적성검사 | 40점 (50분, IT분야 소질·적성) | - |
| 면접 | 20점 (일반면접) | 40점 (심층면접) |

학교생활기록부 종합평가 20점은 출결(6점) + 교내 수상실적(3점) + 자치회 임원활동(3점) + 봉사활동(2점) + 독서활동(6점)으로 세분됩니다. 검정고시 합격자는 별도 산식(140점 만점)을 적용합니다.

**2028학년도 예고**: 반영 교과에 사회·과학이 추가되고 출결 배점이 8점으로 확대되는 등 이후 학년도부터 산출 방식이 바뀔 예정입니다(2027학년도 지원자에게는 적용되지 않습니다).

> 학교 사이트의 "교과점수계산기" 메뉴에서 일반전형(120점 만점)/진로적성특별전형(60점 만점) 기준으로 예상 교과 점수를 직접 계산해볼 수 있습니다.
